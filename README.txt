Floor Plan Dashboard shows your home as a live floor plan. Lamps glow where they hang, rooms show their temperature, blinds and doors their state, and next to each device is the value that matters (°C, %, W). Tap a device for its controls. With a clock, weather and calendar beside it, it is a complete dashboard for a tablet on the wall.

Homey serves the dashboard and the editor as web pages in your own home network, so a wall tablet, laptop or phone only needs a browser. No cloud account and no extra computer.

What you get:

- A dashboard in 2D and in 3D, with real furniture, lamps of the right kind (ceiling, pendant, wall, floor and table lamps) and a wall thermostat that shows the room temperature
- An editor in the browser: draw rooms and walls, place doors, windows, furniture and devices, resize and turn everything, copy and paste, undo
- Start from a picture: add a floor plan image or the PDF of the estate agent, set the scale, and the editor recognises walls, rooms, doors and windows. This happens in your browser; nothing is sent anywhere
- Groups of lamps (made with a group app) work as one lamp
- Several levels, each with its own floor plan
- A Floor plan widget for Homey dashboards
- An optional access code for the web page and a PIN before changes
- Report a problem: an anonymous report for the maker, without names or address

Works together with Energy Dashboard: with both installed, every web page has a switch at the top to go back and forth.
